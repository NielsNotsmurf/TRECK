      Mijn gerechten

        iOS & Garmin koppelen

        1. Garmin Connect → Instellingen → Verbonden apps → Apple Gezondheid: Actieve en Rustenergie aan.
        2. Tik hieronder op Kopieer sleutel.
        3. Installeer de TRECK-opdracht. Plak daarna in beide Get contents of URL-acties je sleutel bij authorization.
        4. Opdrachten → Automation → +: App Garmin Connect Is Closed, en Time of Day 23:55 dagelijks. Beide Run Immediately → TRECK-opdracht.
        5. Druk één keer op ▶️ en controleer hieronder of elke dag binnenkomt.

        Ontvangen (30 dagen)

          Weegschaal

          1. App van de weegschaal → koppel met Apple Gezondheid, Gewicht aan.
          2. Open de TRECK-opdracht en voeg onderaan toe: Find Health Samples → Type Weight, Start Date is in the last 30 days, Sort by Start Date, Order Oldest First.
          3. Daaronder Repeat with Each (Health Samples), en daarin Get Contents of URL: https://treck.nielsscholtes91.workers.dev/api/weight, Method POST, Headers: authorization = je sleutel, date = Repeat Item → Start Date, kg = Repeat Item → Value.
          4. Automation → +: App (app van de weegschaal) Is Closed → Run Immediately → TRECK-opdracht.
          5. Druk één keer op ▶️ en controleer hieronder.
